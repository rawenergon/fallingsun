About RECOX

Autonomous Sky Mesh

RECOX is a mission-grade Drone Management System engineered for coordinated UAV fleets, autonomous delivery corridors, and distributed airspace defense.

🛰️ Dynamic Airspace Corridors: Real-time 4D geofencing and automatic deconfliction over live airspace.
⚡ Peer-to-Peer Swarm Mesh: Resilient decentralized telemetry with zero ground station single-point-of-failure.
🛡️ Autonomous Failsafe: Instant return-to-base and safe descent emergency protocols.

RECOX Fleet SDK

Integrate and dispatch autonomous drone missions programmatically with the RECOX Node/TypeScript SDK. 

npm install @recox/sdk

import { RecoxSwarm } from "@recox/sdk";

const swarm = new RecoxSwarm({ apiKey: "rcx_live_key" });
await swarm.dispatchMission({
  corridor: "sector-04",
  drones: 8,
  speed: "slow"
});
